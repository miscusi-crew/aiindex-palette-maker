# Palette Maker

Generate colour palettes, lock the ones you like, copy the hex codes.

Press Generate (or Space) for a new five-colour palette. Lock the colours you want to keep and generate again.

- Click a colour to copy its hex code
- Save palettes you like; they stay in this browser

## Run it

Open `app/index.html` in a browser. There's no build step and no dependencies: plain HTML, CSS and JavaScript.

On AI Index it runs in the browser with **Run here** (Offline). `aiindex.json` tells AI Index which
folder to serve; its token links this repo to the listing.
